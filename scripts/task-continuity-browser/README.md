# CG-02A task-continuity local browser fixture

Loopback-only, synthetic-data fixture for the three CG-02A continuity repairs. It mounts the **actual** `app.citation-review`, `app.plan` and `app.editor` route components, including the real `CitationForwardPanel`, `AppShell`, Plan `OpportunityDrawer`, Editor, Radix controls and the compiled `src/styles.css`, under a **real TanStack router on hash history**. The address bar, a real page reload and the browser's Back/Forward therefore exercise the routes' own URL handling. It does not record navigation instead of performing it.

## Build and open

```sh
node scripts/task-continuity-browser/build.cjs
python3 -m http.server 8767 --bind 127.0.0.1 --directory /tmp/milo-task-continuity-browser-20261030
```

Then open `http://127.0.0.1:8767/?variant=ready&locale=en`, adding `&check=1` for the scripted report. `MILO_BROWSER_OUT` changes the output directory. The build reads no `.env`, starts no app server and installs nothing.

**Page parameters.** The parameters `locale=en|pl|sv|da`, `variant=…` and `check=1` are moved into `sessionStorage` and removed from the page URL before the router starts. TanStack's hash history parses `location.hash + location.search`, so a page query would otherwise leak into every route location after Back/Forward. Use a new tab, or pass new parameters, to change variant.

The report (`#results`, `window.__taskFixtureReport`) lists every step, any horizontal overflow, the network attempts and the server functions called. Store writes keep their payload, order (`seq`), page (`beforeReload` or `afterReload`), step and confirmation phase, and the audit covers both pages.

- **Back after reload:** before reloading, the script records `expectBack`: the exact router `href` it ended on and the state that location must show. After Back it requires that exact `href`, then the exact visible state. An unhandled expectation fails.
- **`deletionAudit`:** writes are allowed only inside a confirmation phase. A phase starts with the click on the dialog's confirming Delete and ends once that confirmation's save is recorded.
  - Each expected asset needs exactly one phase, in order (`sole`: `asset-a1`, then `asset-c1`; `backbare`: `asset-a1`; other variants: none).
  - Each phase must contain exactly `deleteContentAsset` for that asset id, then `saveWorkspaceNow`.
  - Any write outside a phase fails, including while opening the dialog or navigating before or after it.
  - These are synthetic in-memory writes, not production database or policy evidence.
- **`noNetwork`:** must be true, before and after the reload.
- **`noUnexpectedWrites`:** must be true. Every server call is a read, and `deletionAudit.ok`.
- **`passed`:** every step, no overflow, `noNetwork` and `noUnexpectedWrites`.

The 390×844 phone layout and the keyboard (Tab to **Back to task**, Enter) are for the reviewer to run at that viewport. The script only checks the 44px target when the window is narrower than 640px.

## Boundaries

- **Synthetic stand-ins:**
  - The store (`store.js`) keeps the real `useStore` reading contract (`createSelectorCache` plus shallow equality) over in-page memory. Every other export of `src/lib/store.ts` becomes a recorded refusal at bundle time.
  - Auth (`auth.js`) is a synthetic owner.
  - Every `*.functions.ts` export is replaced. Reads get explicit synthetic answers (citation findings and empty evidence lists) or an honest failure. Any other call is a recorded, refused write.
- **Refused at build time:** `src/integrations/supabase/*` and `.server.ts` modules. The build also checks that the actual route, panel, shell and helper sources are in the bundle.
- **Placeholders:** these subsidiary panels outside CG-02A are replaced by labelled placeholders: CitationReviewPanel, CitationPanelProtocolPanel, CitationBusinessFactsPanel, CitationFindingAuthor, CitationInspectionPanel, EditorialLesson, MiloScorePanel and CreateContentDialog. The `_authenticated` layout, which hydrates the real store, is replaced by an outlet.
- **Network guard:** the inlined `network-guard.js` refuses fetch, XHR, WebSocket, EventSource, sendBeacon and `window.open` before any module runs. The CSP sets `connect-src 'none'`. Fonts use system fallbacks.
- **What this proves:** local interaction evidence with synthetic data only. It is not production or customer acceptance, and it does not test persistence, real hydration, entitlements or server policy.
