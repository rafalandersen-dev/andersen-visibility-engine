# Backlink evidence integrity

The existing Backlinks analysis uses DataForSEO's configured summary, referring-domain and domain-intersection endpoints. This correction does not configure an account, change authority/usage gates, schedule provider work or add automatic retries. Each explicitly requested analysis still uses the existing paid provider/model path.

A valid summary binds to the exact requested hostname. Missing metrics remain null: zero is accepted only when explicitly returned as a valid number. Complete, partial, unavailable and failed summaries remain distinct. An own summary with no usable metrics stops before recommendation generation. Failed competitor requests are retained as failed without fabricated zeros. Numeric strings, negative/nonfinite counts, fractional counts, out-of-range ranks/spam scores, invalid dates, malformed envelopes and mismatched targets fail validation.

Referring-domain and gap tables are bounded samples (25 and 30 rows respectively). Missing/malformed tables fail rather than becoming empty successful responses. Explicit empty arrays are valid; null items require explicit zero item and total counts. Duplicate/invalid domains, count mismatches and oversized samples fail. Intersection keys must match the requested competitor mapping, and referring identities across entries must agree; unknown keys cannot contribute to totals. Missing intersection metrics remain unavailable. No omitted domain establishes absent or lost backlinks. No ongoing new/lost-link monitoring or comparison history is claimed.

Requests retain a 25-second deadline through the response body and accept at most 2 MB before parsing. UTF-8/JSON failures are safe errors. Echoed task target parameters and result target identities must match the requested scope. Provider response bodies, raw messages and network errors are never returned or logged. Provider health responses use the same bounded reader and cannot report ready from a missing account/balance payload.

The actual recommendation prompt distinguishes failed, not-requested and returned samples, labels absent metrics unavailable and prohibits absence/lost-link inferences. Numeric scores are AI estimates; incomplete relevant summary/gap evidence suppresses the corresponding scores. The interface retains source/date/domain context and explains samples, unavailable values and model estimates in English, Polish, Swedish and Danish. Version/source labels in browser-writable workspace records are declarations, not independent verification. Legacy records remain unchanged; their potentially synthesized numeric basis is hidden and original advice is labeled historical.

Response contracts were checked against the provider's [summary](https://docs.dataforseo.com/v3/backlinks-summary-live/), [referring domains](https://docs.dataforseo.com/v3/backlinks-referring_domains-live/) and [domain intersection](https://docs.dataforseo.com/v3/backlinks-domain_intersection-live/) references. Regression fixtures and static rendering do not establish signed-in or live-provider acceptance. R14 provider/supplier/ongoing-monitoring acceptance and D04 remain open; Link Network and sponsored-publication authority are separate. No live provider health/data request, generation, funding, credential setup, outreach, email, publication, migration or timer activation is part of this verification.
