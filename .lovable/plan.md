An isolated, default-off **Synergy Massage** module: evidence → ideas → script/caption/carousel → approval → calendar → manual export. Instagram-first export is the smallest complete MVP; no publishing API is needed.

Read-only audit, 25 November 2026, repository `c5cc7c339d1a2b45bbd6574e2f951527729eab37`: source, migrations, test files, scan results and bounded database SELECTs. Only this plan is written. No application/dependency changes, database writes, provider calls, worker runs, mail, settings changes or deployment. Tests/builds were not run; proposals are not production acceptance or expanded launch authorization.

## Smallest complete MVP

1. **Evidence/ideas:** read existing knowledge without changing it. Manually import excerpts, PDF/DOCX or official reports with URL/title, source language, observed/imported dates, locator, fingerprint, permission-to-use and genuine metrics/window when supplied. URL-only is not evidence. Separate inspiration from factual support; retain unknown/stale/disputed states. No scraping, invented trends, engagement, testimonials or outcomes.
2. **Drafting:** manual editing always works. With separately approved budget, one bounded request proposes up to three ideas; a second for the selected idea returns script scenes, caption/CTA and up to five slides together. Validate claim references against included sources and require human support review; valid IDs alone are not proof.
3. **Carousel:** one 1080×1350 template, 1–5 editable/reorderable slides; approved colors/font/logo, rights-cleared photos and alt text. Reuse image validation and installed JSZip. Browser Canvas rendering; no paid images. Save editable JSON and freeze rendered PNG bytes for review/export. Missing assets/branding or overflow blocks approval, not editing.
4. **Approval/calendar:** owner-only pilot first, matching existing owner approval. Preserve rejected/version history; approval binds text, media bytes, brand/source revisions, language, destination and UTM manifest. Edits invalidate applicability. Dates are planning only, with timezone/UTC instant and DST validation. Delegated viewer/editor/reviewer actions later reuse current project policy, without changing it.
5. **Export/tracking:** approved ZIP contains PNGs, caption/script, alt text, editable JSON and evidence/UTM manifest. Draft-source downloads remain unapproved. Use stable campaign/item IDs, e.g. `utm_source=instagram&utm_medium=organic_social`, never personal data; preserve valid query parameters and validate destinations. Resolve Synergy’s relative booking CTA against its project origin. Record export separately from owner-reported post URL/time/channel. Neither proves publication or conversions. Optional genuine manual report import retains source/window; unknown metrics stay unknown. UTMs do not prove destination analytics captures them.

## Technical design and isolation

- New `src/features/content-factory/`: schemas, pure evidence/version/UTM/calendar helpers, context adapter, repository, authenticated `.functions.ts`, server helpers, browser renderer, views/tests. Thin `_authenticated/app.content-factory` index/sources/editor/review/calendar routes; parent renders Outlet. Reuse AppShell/tokens/controls/i18n; gated navigation and leaf metadata only.
- Extract `projectBrief` into a shared helper with parity tests and unchanged callers; reuse `loadProjectKnowledgeContext` and bounded scoped project/service reads. New manual imports stay in Factory storage: accepting social inspiration cannot change shared brand memory or weekly SEO inputs.
- Additive proposed tables: `content_factory_projects` (trusted flags/limits, brand kit), `content_factory_sources`, `content_factory_items`, immutable `content_factory_versions`, append-only `content_factory_events` (reviews/attempts/exports/reported posts). Owner/project composite keys and project foreign keys, no new auth-schema references. Paginate 50/page; explicit limits fail visibly. Dedicated private Factory storage avoids article promotion/cleanup; reuse validation, not public lifecycle.
- Tenant key: **owning account UUID + project ID**, never name/host/browser active-project state. Actor comes from existing auth middleware. Every operation checks current project/membership/role/flag; approval/export transactionally recheck authority and source/media versions. RLS plus explicit least-privilege GRANTs; no direct client flags/budget/approval grants. Caller-scoped ordinary reads; authorize privileged work before admin access. No cross-project caches or delegate workspace fallback; expiring private links, no credentials in packages/logs.
- Default-off server `contentFactory` gate pinned to the existing Synergy owner/project tuple; never rebound to whoever signs in. Separate AI/local-media/Meta/analytics/autopilot flags, all initially off. Hiding navigation is not authorization. Disablement stops Factory actions without changing website publishing.
- **Forbidden coupling:** no website content/status writes, `scheduled_publishes`, schedule mirrors, publication approvals, weekly readiness/executor changes, existing team-policy setters, publication/preparation worker calls or GA4 daily-job changes. Preserve their gates, schedules and budgets. Factory approval/date/export never invokes a connector.

## EU languages, privacy and costs

Reuse all 24 EU content codes separately from UI/source language. MVP UI EN/PL/SV/DA; Swedish pilot first, other pilot languages on request. Each translation gets separate review; fluent acceptance precedes quality claims. Test diacritics, Greek/Cyrillic, wrapping and Stockholm DST.

Sources are untrusted evidence, never instructions. No patient histories, identifiable treatment records or unconsented photos. Retention/deletion needs explicit policy; no automatic deletion or new tracking without consent. Analytics consent does not authorize publishing/autopilot.

**Factory AI defaults to USD0 until explicit budget approval.** Proposal: USD5/month reservation sublimit INSIDE the existing USD50 global ceiling. Current code reserves USD0.50/text attempt: at most ten attempts under that sublimit, not an invoice estimate. Free accounts still require manual grants. Atomic module/account/global admission and stable attempt IDs; uncertainty retains reservations and prevents regeneration. One attempt/action, no automatic retries/tools/benchmarks; ≤64 KiB prompt, ≤8,000 output tokens, existing 60-second bound, positive completion and strict schema. No subscriptions, new credentials, paid data/images or provider fallback. Provider/deployed budget availability was not verified; hosting/storage is not claimed free.

## Staged rollout and acceptance

1. **Review:** owner approves scope; Claude authors and Codex independently reviews under the working agreement/fallback. Check active writers; confirm owner/assets/rights/samples. Record architecture rules in AGENTS.md during implementation. Approval of this audit does not grant spend or deployment permission.
2. **Manual vertical slice:** isolated test/local schema, import→edit→approve→calendar→ZIP, AI off. Test cross-tenant/project/role denial, forged direct calls, pagination, save/reload, stale evidence, invalidated reviews, missing assets, ZIP bytes/UTMs and DST. Authorized-state browser E2E and desktop/mobile rendering.
3. **Bounded AI pilot:** explicit budget first; narrow receipt extension and Factory persistence before successful delivery/settlement. Fake-provider tests: no-budget/no-dispatch, quotas, concurrency, duplicates, timeouts/uncertain persistence, incomplete JSON, invalid references. Separately budget human Swedish accuracy/brand-fit review; no unlimited evaluation.
4. **Limited release:** separately authorize deployment/Synergy enablement; three approved packages for manual use. Independent review/deep scan, production access/export verification and unchanged website queue/gates evidence. Distinguish exports/reported posts/measured metrics. Rollback disables Factory and retains records.
5. **Later, separate approval:** local FFmpeg/Whisper on owner hardware, not app-server bundles; authenticated bounded jobs, media rights/model/compute/storage limits. Official Meta publishing/analytics after current account/API/scopes review, token handling, idempotent receipts/reconciliation and genuine metric windows. Opt-in autopilot last: explicit project/channel scope, budget, revocation/kill switch and own queue; never inferred from approval, calendar, analytics connection or website autopublish. No consumer automation or terms-violating scraping.

**Validation packet:** new Factory tests plus targeted `bunx vitest run` on existing knowledge, generation-usage, AI-expense, team-review, calendar, language, image-storage, weekly-readiness/executor, publish-cron and GA4-daily tests. Migration authorization tests use the existing isolated harness. Typecheck/production build through required CI/platform checks. Report exact commands/pass counts/errors, paths/SHA and authorized persisted-flow/download evidence. No tests or live acceptance claimed now.
